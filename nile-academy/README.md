# أكاديمية النيل للمحاسبة

تطبيق ويب تعليمي تفاعلي يشرح بالعربية:
- المحاسبة المالية.
- معايير المحاسبة المصرية والدولية.
- القوانين التجارية والضريبية المصرية.

يقوم البرنامج كله على سيناريو شركة خيالية واحدة: **«النيل للصناعات الغذائية ش.م.م»**.

- البرنامج **6 أجزاء**. محتوى **الجزء الأول (الأساس)** و**الثاني (الأصول والتمويل)** و**الثالث (التشغيل)** مكتوب بالكامل، 6 حلقات لكل جزء، والأجزاء من الرابع إلى السادس تظهر في القائمة بعلامة «قريباً».
- كل حلقة فيها 6 أقسام بالترتيب: الموقف ← الشرح ← القاعدة ← التطبيق ← غلطة شائعة ← اختبار.
- تمرين القيد: تختار الحسابات من دليل الحسابات وتكتب المبالغ، فيتحقق التطبيق من التوازن ومن الحسابات والجوانب والمبالغ، ويشرح الخطأ.
- **دفاتر الشركة**: دفتر اليومية، ودفتر الأستاذ لكل حساب، وميزان المراجعة، ودليل الحسابات. تتحدث تلقائياً كلما أنهيت حلقة.
- **القوائم المالية**: قائمة المركز المالي وقائمة الدخل، تُبنى من القيود المرحّلة.
- **حفظ التقدم**: الأقسام التي زرتها، ونتائج الاختبارات، والتمارين المحلولة، والحلقات المكتملة تُحفظ في `localStorage`. لو التخزين محجوب يعمل التطبيق بدون حفظ.
- **المصطلحات**: كل مصطلح أو معيار أو مادة قانونية له معرّف ثابت (مثل `term:accrual-basis` و`eas:10` و`law:17-1999:art21`)، ويظهر عليه تلميح بتعريف قصير. أول مرة يظهر فيها المصطلح في الحلقة يُكتب مقابله الإنجليزي بين قوسين.
- **الواجهة**: اتجاه RTL كامل، ووضع ليلي، وتصميم يناسب الموبايل.

## التشغيل

المتطلبات: Node.js 20.19 أو أحدث (أو 22.12 أو أحدث).

```bash
cd nile-academy
npm install
npm run dev        # خادم التطوير على http://localhost:5173
```

## الاختبارات والبناء

```bash
npm test           # اختبارات المحتوى والمحرك المحاسبي (Vitest)
npm run typecheck  # فحص TypeScript
npm run build      # فحص الأنواع ثم بناء نسخة ثابتة في مجلد dist/
npm run preview    # معاينة النسخة المبنية
```

**ما تتحقق منه الاختبارات:**
- **القيود:** كل قيد في المحتوى متوازن (مجموع المدين = مجموع الدائن). كل حساب مستخدم موجود في دليل الحسابات. كل سطر مدين أو دائن، لا الاثنين معاً.
- **الدفاتر بعد كل حلقة:** ميزان المراجعة وقائمة المركز المالي متوازنان بعد كل حلقة، والقيود تتراكم من حلقة إلى أخرى.
- **الأرقام المذكورة في النص:** الأرقام المكتوبة في المحتوى تطابق ما يحسبه المحرك، مثل رصيد البنك في نهاية كل حلقة وإجماليات القوائم.
- **التمارين:** حل كل تمرين قيد ينجح في المصحح الآلي.
- **الاختبارات:** كل اختبار فيه من 4 إلى 6 أسئلة، ولكل سؤال إجابة صحيحة واحدة.
- **المصطلحات والمراجعة:** كل معرّف مصطلح مستخدم موجود في القاموس، وكل شارة «يحتاج مراجعة» لها بند مسجل في `VERIFY.md`.

## النشر

ناتج `npm run build` ملفات ثابتة في `dist/` تُرفع على أي استضافة ثابتة (GitHub Pages، Netlify، Cloudflare Pages، أو أي خادم ويب) بدون إعداد إضافي:
- التنقل يعمل بالـ hash (`#/episode/p1e1`)، فلا يحتاج الخادم إلى إعادة توجيه المسارات.
- المسار الأساسي نسبي (`base: './'`)، فيعمل التطبيق من أي مجلد فرعي.

## هيكل المشروع

```
nile-academy/
├─ content/                    ← كل المحتوى (لا يحتاج تعديل كود)
│  ├─ program.json             ← الأجزاء الستة وحالة كل جزء وحلقاته
│  ├─ company.json             ← بطاقة الشركة والتبسيطات
│  ├─ chart-of-accounts.json   ← دليل الحسابات ومجموعات القوائم المالية
│  ├─ glossary.json            ← المصطلحات والمعايير والقوانين بمعرّفات ثابتة
│  └─ parts/part-1/ep-01.json … ep-06.json
├─ src/
│  ├─ engine/      ← المحرك المحاسبي: الترحيل، والأستاذ، وميزان المراجعة، والقوائم، ومصحح القيود
│  ├─ components/  ← JournalTable، EntryExercise، Quiz، Term، RichText…
│  ├─ pages/       ← الرئيسية، والشركة، والحلقة، والدفاتر، والقوائم، والمصطلحات
│  ├─ store/       ← حفظ التقدم
│  ├─ content.ts   ← تحميل ملفات المحتوى تلقائياً
│  └─ types.ts     ← شكل ملفات المحتوى
├─ tests/
├─ SOURCES.md      ← المراجع
└─ VERIFY.md       ← المعلومات التي تحتاج مراجعة من مصدر رسمي
```

## إضافة حلقة جديدة

1. أنشئ ملف JSON في مجلد الجزء، مثل `content/parts/part-2/ep-01.json`. أسهل طريقة: انسخ حلقة موجودة وعدّلها، والشكل الكامل موصوف في النوع `Episode` في `src/types.ts`. الحقول الأساسية:
   - `id`: معرّف فريد مثل `p2e1`.
   - `part` و`number`: رقم الجزء ورقم الحلقة.
   - `situation`، `explanation`، `mistake.blocks`: مصفوفات «كتل». الكتلة إما نص (فقرة)، أو كائن من نوع:
     - `heading`: عنوان.
     - `list`: قائمة، وتكون مرقمة لو أضفت `"ordered": true`.
     - `table`: جدول (`headers` و`rows`).
     - `callout`: صندوق تنبيه (`tone`: `info` أو `warning` أو `success` أو `law`).
   - `rule.refs`: المواد والمعايير. لكل مرجع `id` من القاموس، و`text`، واختيارياً `counterpart` (المقابل الدولي) و`review` (بند مراجعة).
   - `application.entries`: القيود. كل سطر فيه `account` (كود من دليل الحسابات) ومعه `debit` **أو** `credit`. القيد الذي فيه `"post": false` توضيحي فقط ولا يُرحَّل إلى الدفاتر.
   - `quiz.questions`: من 4 إلى 6 أسئلة. لكل خيار `explanation`، والخيار الصحيح عليه `"correct": true`.
   - `quiz.exercises`: تمرين قيد واحد على الأقل. فيه `solution` (الحل)، و`hints` (تلميحات)، و`explanation` (شرح الحل).
2. سجّل الحلقة في `content/program.json` داخل `episodes` للجزء المطلوب:
   ```json
   { "id": "p2e1", "number": 1, "title": "…", "file": "parts/part-2/ep-01.json" }
   ```
3. شغّل `npm test`. لو في قيد غير متوازن، أو حساب أو مصطلح غير معرف، أو ميزان مراجعة لا يتوازن، سيفشل الاختبار ويوضح السبب.

**تنسيق النص داخل المحتوى:**

| الصيغة | الاستخدام |
|---|---|
| `**نص**` | نص غامق |
| `{{term:accrual-basis\|أساس الاستحقاق}}` | مصطلح عليه تلميح. النص بعد `\|` هو الذي يظهر |
| `{{eas:10}}` | يظهر اسم البند كما في القاموس |
| `{{review:V03}}` | شارة «يحتاج مراجعة» مربوطة بالبند V03 في `VERIFY.md` |

## إضافة جزء جديد

1. في `content/program.json` غيّر حالة الجزء من `"coming-soon"` إلى `"available"`، وأضف حلقاته في `episodes`.
2. أضف ملفات الحلقات في `content/parts/part-N/`.
3. لو احتجت حسابات جديدة (مثل مجمع الإهلاك)، أضفها في `content/chart-of-accounts.json` بكود يتبع الترقيم:
   - `1xxx` أصول.
   - `2xxx` التزامات.
   - `3xxx` حقوق ملكية.
   - `4xxx` إيرادات.
   - `5xxx` مصروفات.

   الحساب المقابل يأخذ `"contra": true`.
4. لو احتجت مصطلحات أو مراجع جديدة، أضفها في `content/glossary.json` بمعرّف ثابت. لا تغيّر المعرّفات الموجودة، لأن الدليل المرجعي سيعتمد عليها.

## الدقة والمراجع

- المحتوى مبني على معايير المحاسبة المصرية (قرار وزير الاستثمار 110 لسنة 2015 وتعديلاته)، مع ذكر المعيار الدولي المقابل.
- **القوانين المرجعية:**
  - قانون الشركات 159 لسنة 1981.
  - قانون سوق رأس المال 95 لسنة 1992.
  - قانون التجارة 17 لسنة 1999.
- أي معلومة لم نتحقق منها من نص رسمي عليها شارة «يحتاج مراجعة» ومسجلة في [VERIFY.md](VERIFY.md).
- المراجع في [SOURCES.md](SOURCES.md).
- الشركة خيالية، والأرقام لأغراض التعليم.
